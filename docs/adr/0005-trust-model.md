# ADR-0005：採信任模型，不驗證實名

**Status**: Accepted

## Context

系統要求成員填寫真實姓名，但無任何驗證機制（無學號比對、無管理員逐一核可）。

## Decision

接受此限制。任何取得房間碼者皆可以任意姓名加入。

## Consequences

**代價**：
- 任何取得房間碼者可冒名加入，取得全體成員的實名與照片。
- 成員之間無法確認牆上的名字屬實。
- 一旦發生冒名，僅能事後補救，無法事前阻擋。

補償控制：管理員可停權、可重新產生房間碼使舊碼失效、可關閉加入開關（§8.4）。
此三項合計已足以應付 24 人封閉團體的威脅模型。
