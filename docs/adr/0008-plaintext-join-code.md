# ADR-0008：房間碼明文儲存，僅管理員可讀

**Status**: Accepted

## Context

房間碼是否應如密碼般雜湊儲存？

## Decision

明文儲存於 `rooms.join_code`。存取以 RLS policy 限制為僅管理員可讀，一般讀取走不含此欄位的 `rooms_public` view。

## Consequences

**代價**：
- 資料庫被讀取時房間碼直接外洩，無雜湊作為第二層防護。
- 管理員帳號被盜即等同房間碼外洩。

理由：房間碼本質不是密碼。它會被口頭傳播、寫在群組公告，且管理員必須能隨時複述給成員。雜湊會使「管理員查看目前房間碼」這個必要功能無法實作。
房間碼因此不得作為唯一防線，必須配合 rate limit（§8.3）與關閉加入開關（§8.4）。
