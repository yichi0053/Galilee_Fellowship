# ADR-0007：否決自由座標拖曳，採依週分區加 masonry

**Status**: Accepted

## Context

原構想為真實佈告欄的隱喻：成員可自由拖曳貼文到牆上任意位置。

## Decision

否決。改為依週分區，區內以 masonry 自動排列，卡片帶 -3 至 +3 度的固定隨機旋轉角製造手貼感。

## Consequences

**代價**：
- 失去「真實佈告欄」的自由感，這是原構想中最強的視覺記憶點。
- 成員無法透過擺放位置表達關係（例如把自己的貼文放在朋友旁邊）。

否決理由：
- 18 週約 1,296 則貼文，自由座標必然重疊遮蔽。
- 手機上的觸控拖曳與頁面捲動手勢直接衝突。
- 不同螢幕寬度的座標換算無良解。
- 開發成本 15 小時以上，且是全案風險最高的部分。

替代投資：落下動畫、進場動畫、lightbox 合計約 5 小時，視覺記憶點來自質感與動態而非拖曳。
